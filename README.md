# Namma_Yatri_Data_Analysis

Data Analysis of Namma Yatri Dataset on Rides, Fares and Business Point of view

**Problem Statement**
To provide actionable insights to the management of Namma Yatri focusing on improving:
The Ride industry facing challenges like trip cancellations, demand supply mismatches, fare fluctuations. This analysis aims to develop Power BI dashboard to optimize operations and enhance customer experience.
